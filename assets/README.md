# Portfolio visuals

These are original graphics for Alex Haya's GitHub profile.

| File | Purpose |
| --- | --- |
| `banner.svg` | Name, engineering focus, and visual identity |
| `projects.svg` | Implementation sketches for three public repositories |
| `rl-gym-workflow.gif` | Animated conceptual diagram of RL Gym's main queued evaluation path |
| `rl-gym-workflow.png` | Static version of the same architecture diagram |

Visual inspiration: [Beautiful UI](https://www.beautifului.dev/), particularly its charcoal cards, restrained accents, compact labels, and dotted workflow canvas. These assets are original illustrations, with no copied component code or screenshots.

The animation illustrates execution order. It does not represent live telemetry, measured latency, benchmark results, or an application recording. The architecture sketch omits secondary paths and fallback behavior.

The public project sketches are grounded in the source files linked from the profile README. Written descriptions and alternative text accompany the images so the profile remains understandable without them.
