Verifying the preserved report files.

  • Report integrityReading

    Each report is checked against the SHA-256 hash in its preserved provenance manifest before its records are displayed.

  • Run identityReading

    Begin, sample and done records must share a run identity. Model and dataset identities must match the report summary.

  • Complete observationsReading

    Observation counts, unique sample/repetition pairs and the aggregate error are checked against the actual record stream.

  • Physical-board validationNot run

    These archived records describe emulator execution. They do not establish physical-device speed, power consumption or application accuracy.
